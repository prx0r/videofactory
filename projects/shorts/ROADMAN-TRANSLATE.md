## Method (granny-distill + roadman-shorts, applied)
1. Take the granny span (verbatim-mapped bids, liberation-tested).
2. Find the mechanism, not the term (what would change tomorrow?).
3. Pick a London vehicle from london-bank.json that runs the SAME
   mechanism (night bus = bardo transit, meal deal = karma economy,
   Turkish barbers = trimming the self).
4. Attach the banked GIF whose watch-notes show the image (or file a
   wanted brief if none exists).
5. Write Roady in register (lexicon file): mate-directed, GIF-first,
   minted word allowed, banned list never. Maps_to every line.
