# granny-distill (needs owner — taste + liberation test)

Symptom: a sixty-second granny script that teaches nothing — a Sanskrit
definition, a summary of a summary, content nobody could use.

Diagnosis: wrong question asked. Never "what is X" — ask "what concept
from any long-form video, explained in 30–60 seconds, would genuinely
help or liberate someone?" The liberation test: would hearing this
change what someone DOES tomorrow morning? Definitions fail it;
mechanisms pass it (how grasping builds a self, how the show keeps
running, how to stop feeding it).

Fix: mine long-form for mechanisms, not terms. Condense verbatim-first
(cut lines, never paraphrase warmth away); keep the one joke that
carries the idea and cut the two that decorate it. Sixty seconds is
~140 spoken words; forty-five is braver. Every kept line maps to source
bids. Output: the 60s script + maps_to + the Roady brief it implies
(one GIF, one concept, one mode call).

Process note: this skill runs FIRST in the shorts line — granny's
minute exists before Roady's. If no concept in the span passes the
liberation test, the span yields no short; never manufacture one.
