# roadman-shorts (needs owner — creative judgment, ear-blessed)

Symptom: a short needs Roady's voice and the draft reads flat — one
register throughout, GIF as wallpaper, jokes that explain nothing.

Diagnosis: Roady has MODES and the topic picks the mode, not the writer.
Ramble mode: one GIF up, Roady talks around it with a personal story
that lands the image (dog, lamp, raft — images with a past). Quickfire
mode: GIFs popping in sequence ("ok we got a new one"), Roady reading
each live, ten seconds apiece (chariots, scales, examinations — lists
and processions). Mixed mode: ramble opens, quickfire proves, ramble
closes. Pick by topic: dwelling images ramble, processions quickfire.

Fix: hook-first cold open on the punch line. GIF AS BIG AS POSSIBLE —
picture fills the frame, captions ride its quiet zones (small-emblem
minimalism is long-form law, not Roady's). New GIF pops BEFORE any talk
about it. Made-up words freely ("syllogical") with TRUE doctrine
underneath — wrong words, right Dharma, every time; that gap IS the
comedy. Close with the mutter after Big G takes over ("nah she's proper
rude innit — sounds kinda leng tho"). Register: ROADMAN draft bans
cap/fr/bussin/vibe/delulu/lowkey (verified zero hits). Frame: Roady sees
the GIF fresh, talks to his mate; one concept per sixty seconds (spanda,
prakasa, what is Siva?).

Process note: every Roady line carries maps_to source bids (C2 rule);
granny's 60 seconds get written first, Roady's generated off it, handoff
links them. Voice: roadman seat, free model only. Nothing renders on
provisional voice without ears.

## Graph rule (comedy-graph-v1, core/knowledge/comedy-graph.json)
New bits are built, not found: take a proven house SO (owner/owned,
sacred/profane, eternal/urgent) + a proven LM (bureaucratic-reframe,
bathos, garden-path) + a FRESH situation from the current chapter.
Same SO+LM+situation as an existing node = same joke: forbidden.
Check the graph before writing; file every aired bit back as a node.
